# Tic Tac Toe
This is tic tac toe browser game.

## *Insight*
It took an understandable amount of time to get this done with the time constraint placed. I took a round-about way to get this done, perhaps an unusual path, but I believe is essential as a learning experience. I had quite a bit of time scratching my head about the right pattern to place the logic, perhaps to avoid unnecessary inconsistencies that could prove bug prone. I really do have a way to go. It was quite the experience. I aimed for a minimalist ui with very little distraction to assist the user experience. I hope you like it.

## Conclusion
This is a pretty nice project to get an even deeper understanding of DOM manipulation, states and deepen your foundation for bigger, greater projects. It is an intermediate project, definitely worth your time. Think deeply and ponder just the many possibilities of what code is poissible of doing.
